### Cómo usar las carpetas

1. Clona el repo: `git clone https://github.com/nemesis312/boricuacoder-youtube.git`
2. Entra a la carpeta del video que te interesa, por ejemplo `videos/01-agente-seguridad`.
3. Lee el `README.md` de esa carpeta: explica qué hace, los requisitos, cómo instalarlo y sus límites.
4. Copia los archivos que necesites a tu propio proyecto. Cada carpeta es independiente de las demás.

## English

This repository holds the code that goes with the BoricuaCoder YouTube videos. Each video has its own folder under `videos/` with everything you need to repeat the demo on your machine. The videos are in Spanish.

- YouTube channel: https://www.youtube.com/@boricuacoder
- Blog (videos and articles): https://blog.boricuacoder.dev/videos/

### Videos

| # | Title | YouTube | Folder | Article |
|---|---|---|---|---|
| 01 | Crea un agente de IA que revise tu código ANTES de cada commit (Spanish: "Build an AI agent that reviews your code BEFORE every commit") | [Watch](https://youtu.be/Cmw1km8dR5U) | [`videos/01-agente-seguridad`](videos/01-agente-seguridad) | [Read on the blog](https://blog.boricuacoder.dev/blog/first-ai-agent-security-reviewer-en/) |
| 02 | Cómo crear una skill para Claude Code (Spanish: "How to create a Claude Code skill") | [Watch](https://youtu.be/jkUsPg7dUhc) | [`videos/02-crear-skills`](videos/02-crear-skills) | [Read on the blog](https://blog.boricuacoder.dev/blog/crear-skills-en/) |

### How to use the folders

1. Clone the repo: `git clone https://github.com/nemesis312/boricuacoder-youtube.git`
2. Go to the folder of the video you want, for example `videos/01-agente-seguridad`.
3. Read that folder's `README.md`: it explains what it does, the requirements, how to install it and its limits.
4. Copy the files you need into your own project. Each folder is independent from the others.
